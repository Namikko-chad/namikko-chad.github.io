Под это — своя платформа из независимых Go-сервисов с общей дизайн-системой. A studio where ideas become running services through an automated pipeline: AI agents plan, build, test and deploy, an engineer reviews and decides what ships.   • CloudSync

    GPL-3.0

    Синхронизация файлов между Linux, Windows и Android без сервера. Данные шифруются на устройстве и раскладываются по облакам, которые у вас уже есть (Drive, Mega, S3, WebDAV…) с избыточностью Reed-Solomon k+m — потеря одного облака не страшна. Плюс менеджер паролей, SSH- и web3-ключей и 2FA. File sync between Linux, Windows and Android with no server. Data is encrypted on the device and spread over the clouds you already have (Drive, Mega, S3, WebDAV…) with Reed-Solomon k+m redundancy — losing a cloud loses nothing. Includes a vault for passwords, SSH and web3 keys and 2FA.

    MIT

A full AmneziaWG (obfuscated WireGuard) client as a RouterOS 7 container with a web UI. Paste a vpn:// key and route the whole LAN, chosen devices or chosen sites through the tunnel; kill switch, per-country exceptions, automatic failover. ~10 MB image, ~8 MB RAM.
